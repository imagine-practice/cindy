## 页面、字段与记录一致性

| 页面 | 主要字段 | 主路径与回流 |
| --- | --- | --- |
| S1 项目概览 | 目标、固定 M1/r1 范围、已独立验收数、当前候选、待决与下一责任人 | S2 来源、S3 标准、S4 计划、S5 验收、S6 交付 |
| S2 群聊与来源 | 群成员/负责人、话题、原消息 M-18、需求卡、D-01 决定卡、交付卡、同步范围 | M-18 → R-01；交付卡 → REL-01；群设置中新增关联 |
| S3 需求与决定 | R-01 r1、包含/不含、设计 d1、AC-01～04、决定者/选项/影响、修订 | 回原消息；计划；固定 A/B 标准；R-02 为部分退款新草稿 |
| S4 计划与执行 | 四个工作项、依赖/并行、负责人、写域、指导、输入/产物、独立验证者、模型策略与实际回执 | 任务包/执行尝试/模拟原生任务用抽屉；回同一工作项；固定候选 |
| S5 候选与验收 | C-A/build-a01、C-B/build-b02、固定 r1/d1/k1、环境、AC 预期/实际、失败 I-01、未覆盖 | A 失败 → W-API 原作者修复 → B 单独复验；A 不被覆盖 |
| S6 交付反馈 | REL-01、目标环境、版本、入口核验、回退、通知、F-01/F-02 | 发布与通知分别恢复；群交付卡回 S2；缺陷回原工作，新范围回 R-02 |

默认首次打开 S2 未关联群。实际可点主线：创建并关联表单 → 同群项目卡 → S1 → 回原消息整理需求 → S3 决定 → 纳入 S4 → 开始并发 → 提交 A → S5 失败返工/B 复验 → S6 交付 → S2 交付卡。名称、目标、协调负责人在同一内存状态保存；取消/校验失败不创建，创建不执行。刷新重置。

每页底部可展开“设计标注”，标注实际源码路径及现有/新增边界。阶段控件在原型工具区，和产品控件分开；切到后续演示阶段会准备相应示例记录。固定范围只统计已独立验收的工作项，不表示工时或全部项目完成率。运行结束、候选自测、独立验收和发布是四个不同事实。阶段切换不会把 A 的结论改成 B。

## D0.1 评审条目覆盖

以下是原型设计及作者自查的覆盖，不代替独立 QA。

| 条目 | 页面与本轮覆盖 | 剩余界限 |
| --- | --- | --- |
| RV-01 | S2 原消息首次整理 R-01，后续同入口打开已存在记录；接入预览标重，不重复派发 | 没有真实数据持久化 |
| RV-02 | S3 回 S2 定位 M-18，浏览器返回保留记录路由 | 精确滚动/焦点回原控件未全面验证 |
| RV-03 | 待决定阶段与业务决定影响明确；不能提前发布 | “制作后退款”未单列，示例使用全额/部分范围待决 |
| RV-04 | S4 共享契约 k1 → API/UI 并行 → 独立验收 | 仅示例依赖，无调度执行 |
| RV-05 | 任务包 ↔ 执行 ↔ 原生任务示例标识固定 | 两条同名真实任务选择未做 |
| RV-06 | A 失败 → 原工作项/原作者返工，自测与质量分开 | 失败数据是假设示例 |
| RV-07 | B 提交、待复验、复验通过；A 历史保留，证据绑定各自构建 | 无真实证据文件或测试执行 |
| RV-08 | r1/r2 影响对比，旧证据只对旧范围有效 | 多人版本冲突解决仅设计摘要 |
| RV-09 | 发布/入口核验独立字段，未就绪发布禁用；恢复抽屉说明 | 命令成功但入口不可达的完整状态机未交互模拟 |
| RV-10 | 已发布后演示通知失败/单独重试，发布不回退 | 未模拟真实超时查询 |
| RV-11 | S6 部分退款 → R-02 草稿；原缺陷回原范围 | 新范围未推进到下一里程碑 |
| RV-12 | 群关联不授予权限、同步范围与私有内容界限明确 | 成员级权限裁剪未模拟、未验证 |
| RV-13 | 六页 320/390 宽度无文档横向溢出；浅深截图；抽屉 Esc/焦点约束 | 移动实机、屏幕阅读器、全部键盘往返未完成 |
